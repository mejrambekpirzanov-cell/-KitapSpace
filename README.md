# KitapSpace — Онлайн кітапхана

KitapSpace — кітаптарды іздеуге, оқуға және таңдаулы кітаптарды белгілеуге арналған онлайн кітапхана.

## Файлдар
- `index.html` — сайттың негізгі беті.
- `style.css` — сайттың сыртқы көрінісі.
- `script.js` — тіркелу, кіру, іздеу, бетбелгілер және басқа интерактивті мүмкіндіктер.
- `Gemini_Generated_Image_g1dcng1dcng1dcng.jpg` — сайт логотипі.
- `harry-potter.mp3` — аудиокітап файлы.

## Жергілікті іске қосу
`index.html` файлын браузерде ашыңыз немесе VS Code ішіндегі Live Server кеңейтімін пайдаланыңыз.

## Қолданылған технологиялар
HTML, CSS, JavaScript, Local Storage.
